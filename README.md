# GlintWare
![GlintWare](watermark.png)
GlintWare is a free tool projected to detect any changes that occurred after a Windows session starts. It works by using the Windows registry to load all logs regarding the start of processes (both on disk and in RAM), the start of files, and the modification of files and processes from the recent BIOS Boot
# Package Native Injectable Executable File
Have you noticed our funny format called **PNIE**? It was made to set us apart and we are proud of it. If you're wondering how you can open this file, don't worry, it's just a zip...
# How i use this?
You have only to open this file with a zip program like Winrar or 7zip. Than you have to extract the file content and start **GlintWare.bat** and the rest will take care of itself. You have to accept the UAC
